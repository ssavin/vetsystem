  ВНЕШНЯЯ ОБРАБОТКА: Отчёт Розничных Продаж Ветаис → 1С
═══════════════════════════════════════════════════════════════════

ШАГ 1 — УСТАНОВИТЬ ODBC ДРАЙВЕР для PostgreSQL (один раз)
──────────────────────────────────────────────────────────
На компьютере где запущена 1С должен быть установлен psqlODBC:
  https://www.postgresql.org/ftp/odbc/versions/msi/
  → скачать: psqlodbc_16_xx_0000-x64.zip (или последнюю версию)
  → установить psqlodbc_x64.msi

═══════════════════════════════════════════════════════════════════
  ВАРИАНТ А — через XML файл (автоматически)
═══════════════════════════════════════════════════════════════════

1. Откройте 1С Конфигуратор (режим Конфигуратора, не Предприятия)
2. Файл → Открыть → выберите vetais_retail_report.xml
3. Конфигуратор скомпилирует и откроет обработку
4. Файл → Сохранить как → выберите .epf
5. Готовый .epf файл загружайте в 1С:Предприятие через:
   Файл → Открыть → vetais_retail_report.epf

═══════════════════════════════════════════════════════════════════
  ВАРИАНТ Б — создать вручную (если XML не загружается)
═══════════════════════════════════════════════════════════════════

1. Откройте 1С Конфигуратор
2. Файл → Новый → Внешняя обработка
3. В дереве метаданных щёлкните правой кнопкой на "Формы"
   → Добавить → назовите "ОсновнаяФорма" → Основная: ДА

4. В форме добавьте реквизиты (вкладка "Реквизиты"):
   ┌──────────────────────┬──────────────────────────────┬───────────┐
   │ Имя                  │ Тип                          │ Заголовок │
   ├──────────────────────┼──────────────────────────────┼───────────┤
   │ Хост                 │ Строка (длина 255)            │ Сервер    │
   │ Порт                 │ Строка (длина 10)             │ Порт      │
   │ База                 │ Строка (длина 255)            │ База      │
   │ Пользователь         │ Строка (длина 100)            │ Польз-ль  │
   │ Пароль               │ Строка (длина 100)            │ Пароль    │
   │ ДатаС                │ Дата (тип: Дата)              │ Период с  │
   │ ДатаПо               │ Дата (тип: Дата)              │ по        │
   │ Организация          │ СправочникСсылка.Организации  │ Орг-ция   │
   │ Склад                │ СправочникСсылка.Склады        │ Склад     │
   │ НоменклатураУслуги   │ СправочникСсылка.Номенклатура │ Услуги    │
   │ НоменклатураТовары   │ СправочникСсылка.Номенклатура │ Товары    │
   │ СтавкаНДС            │ ПеречислениеСсылка.СтавкиНДС  │ НДС       │
   │ РезультатОтчета      │ Строка (длина неограниченная) │ Результат │
   └──────────────────────┴──────────────────────────────┴───────────┘

5. В форме разместите:
   [Поле ввода]   Хост               "Сервер"
   [Поле ввода]   Порт               "Порт"
   [Поле ввода]   База               "База данных"
   [Поле ввода]   Пользователь       "Пользователь"
   [Поле ввода]   Пароль             "Пароль" → свойство РежимПароля: ДА
   [Поле даты ]   ДатаС              "Период с"
   [Поле даты ]   ДатаПо             "по"
   [Поле выбора]  Организация        "Организация"
   [Поле выбора]  Склад              "Склад"
   [Поле выбора]  НоменклатураУслуги "Номенклатура (услуги)"
   [Поле выбора]  НоменклатураТовары "Номенклатура (товары)"
   [Поле выбора]  СтавкаНДС          "Ставка НДС"
   [Кнопка]       СформироватьОтчет  "Создать документ в 1С"
   [Поле текста]  РезультатОтчета    "Результат" (только чтение)

6. Откройте модуль формы и вставьте КОД из файла:
   vetais_retail_report_MODULE.bsl

7. Сохранить → Файл → Сохранить в файле (.epf)
