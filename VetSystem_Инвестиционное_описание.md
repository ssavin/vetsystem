# VetSystem — Инвестиционное описание платформы

**Дата:** Март 2026  
**Тип:** SaaS-платформа для управления ветеринарными клиниками  
**Стадия:** Коммерческая эксплуатация, активный рост клиентской базы

---

## 1. Краткое описание

**VetSystem** — это комплексная многопользовательская SaaS-платформа для автоматизации работы ветеринарных клиник. Система охватывает весь цикл работы клиники: от первого звонка клиента до выдачи документов после лечения. Платформа работает как облачный сервис с посещением через браузер, мобильное приложение для владельцев питомцев и офлайн-приложение для работы без интернета.

Система уже находится в продуктивной эксплуатации в нескольких клиниках с совокупной базой более **100 000 клиентов, 100 000 пациентов и 520 000+ обработанных счетов**, мигрированных из предыдущих систем.

---

## 2. Проблема

Российский рынок ветеринарных услуг активно растёт на фоне роста числа домашних животных и повышения культуры их лечения. При этом большинство клиник работают:

- **На устаревшем ПО** — системы 2005–2015 годов, не адаптированные под современные требования (мобильность, интеграции, онлайн-запись)
- **На бумаге или Excel** — потеря данных, дублирование, ошибки персонала
- **Без связи между отделами** — регистратура, врачи, склад и бухгалтерия работают разрозненно
- **Без аналитики** — руководители клиник принимают решения вслепую, без данных о выручке, загрузке врачей, популярности услуг
- **Без мобильного взаимодействия с клиентом** — владельцы питомцев не могут записаться онлайн или получить историю лечения

Существующие решения либо слишком дорогие для малых клиник (1С-системы), либо не соответствуют российским требованиям по фискализации, либо не покрывают полный цикл работы ветклиники.

---

## 3. Решение — VetSystem

VetSystem закрывает все эти боли одной платформой. Ключевые характеристики:

- **Многофилиальность** — одна учётная запись для сети клиник, полная изоляция данных между арендаторами
- **Полный цикл** — от регистратуры и записи до стационара, лаборатории и финансов
- **Три платформы** — веб-приложение, мобильное приложение для клиентов, офлайн-десктоп для работы без интернета
- **Российская специфика** — фискализация чеков, требования 152-ФЗ по персональным данным, интеграция с российскими сервисами (МойСклад, Mango Office, ЮKassa, Дримкас)
- **Быстрый старт** — 14 дней бесплатного периода, миграция данных из старых систем включена в тариф «Бизнес»

## 4. Функциональные модули

Система состоит из **12 полноценных модулей**, покрывающих весь операционный цикл клиники:

### Регистратура
- Быстрый поиск по ФИО, телефону, номеру микрочипа
- Карточка клиента: история визитов, документы, звонки
- Карточка пациента: порода, возраст, прививки, история болезни
- Поддержка нескольких владельцев у одного питомца
- Автоматическое открытие карточки клиента при входящем звонке

### Расписание
- Визуальный календарь: день / неделя / месяц
- Управление расписанием врачей и кабинетов
- SMS и push-напоминания клиентам
- Онлайн-запись через мобильное приложение

### Электронные медицинские карты
- Структурированные записи осмотров по шаблонам
- Клинические случаи с группировкой нескольких визитов в один эпизод лечения
- Прикрепление файлов, рентгеновских снимков, результатов анализов
- Генерация PDF-документов: выписки, справки, направления, согласия

### Стационар (Госпитализация)
- Управление клетками: статусы «свободна / занята / обслуживание»
- Приём пациента с автоматическим созданием черновика счёта
- Журнал процедур с автоматическим добавлением в счёт
- Автоматическое начисление услуги «Сутки пребывания» каждую ночь (cron)
- Выписка с финализацией счёта на кассе

### Лаборатория
- Направления на анализы с автозаполнением
- Интеграция с анализаторами по протоколам ASTM / LIS2-A2
- Поддержка лабораторий Invitro Vet, Vet Union, Chance Bio
- Просмотр результатов и прикрепление к медкарте

### DICOM / Рентген
- Загрузка и просмотр DICOM-файлов прямо в браузере
- Привязка снимков к истории болезни пациента

### Финансы и счета
- Выставление счетов с позициями по услугам и товарам
- Черновые счета для стационара, финальные — для кассы
- Интеграция с онлайн-кассами через Дримкас Start
- Приём оплаты через ЮKassa
- Отчёты по выручке, задолженностям, возвратам

### Склад и номенклатура
- Учёт товаров и услуг
- Двусторонняя синхронизация с МойСклад
- Списание при использовании в лечении

### Электронная очередь
- Экран для клиентов в зале ожидания
- Атомарная нумерация талонов с ежедневным сбросом
- Вызов через интерфейс регистратора

### CRM и коммуникации
- История взаимодействий с клиентом
- Входящие звонки с автоматическим поиском клиента по номеру (Mango Office)
- Запись разговоров с воспроизведением в карточке клиента
- Push-уведомления через мобильное приложение

### Аналитика и отчёты
- Дашборд с ключевыми показателями: выручка, загрузка, новые клиенты
- Отчёты по врачам, услугам, периодам
- Инструменты для прогнозирования и анализа динамики

### ИИ-ассистент
- Встроенный чат-ассистент на базе OpenAI
- Помощь в составлении протоколов, ответах на вопросы по препаратам

## 5. Технологическая платформа

Система построена на трёх взаимосвязанных приложениях:

### Веб-приложение (основное)
- **Frontend:** React 18 + TypeScript, Vite, Shadcn/ui, TailwindCSS
- **Backend:** Node.js + Express, TypeScript, REST API
- **База данных:** PostgreSQL с полной изоляцией данных между клиентами (Row-Level Security)
- **Документы:** генерация PDF через Puppeteer + Handlebars-шаблоны
- **Авторизация:** JWT с многоуровневыми ролями (суперадмин / admin / врач / регистратор)
- **Уведомления:** WebSocket (Socket.IO) для оповещений в реальном времени

### Мобильное приложение для клиентов (владельцы питомцев)
- **Технология:** React Native + Expo (iOS + Android)
- **Вход:** через SMS-код (интеграция с SMS.RU)
- **Функции:** просмотр питомцев, история визитов, онлайн-запись, чат с клиникой, push-уведомления о прививках и обработках, доступ к медицинским файлам

### Офлайн-десктоп (Companion)
- **Технология:** Electron + React + SQLite
- **Назначение:** полноценная работа клиники при нестабильном или отсутствующем интернете
- **Синхронизация:** двусторонняя, автоматически каждые 60 секунд при восстановлении связи
- **Функции:** регистратура, расписание, счета, номенклатура
- **Дистрибуция:** .exe-установщик для Windows (Mac/Linux готово к сборке)

### Касса (Desktop POS)
- Отдельное Python-приложение для розничных продаж
- Интеграция с фискальным принтером

## 7. Бизнес-модель

VetSystem работает по модели подписки (SaaS) с ежемесячной оплатой.

| Тариф | Цена | Для кого |
|---|---|---|
| **Старт** | 9 900 ₽/мес | 1 филиал, до 5 пользователей, базовые модули |
| **Профи** | 24 900 ₽/мес | До 3 филиалов, до 15 пользователей, все модули включая лабораторию, стационар, мобильное приложение |
| **Бизнес** | По запросу | Сети клиник: неограниченные филиалы и пользователи, SLA, выделенный сервер, миграция данных, обучение на месте |

**Дополнительные источники выручки:**
- Первичное внедрение и настройка
- Миграция данных из старых систем
- Кастомные интеграции и доработки под клиента
- Обучение персонала

**Пробный период:** 14 дней с полным функционалом тарифа «Профи», без привязки карты.

## 9. Конкурентные преимущества

**1. Полный охват цикла клиники**  
Большинство конкурентов закрывают 2–3 модуля (расписание + карты). VetSystem покрывает все 12 — от регистратуры до стационара и аналитики.

**2. Три платформы в одном продукте**  
Веб + мобайл для клиентов + офлайн-десктоп. Ни один российский конкурент не предлагает офлайн-режим со смарт-синхронизацией.

**3. Глубокая российская специфика**  
Фискализация по 54-ФЗ, DADATA, Mango Office, МойСклад, SMS.RU — не надстройки, а встроенные интеграции.

**4. Архитектура для сетей**  
Multi-tenant с полной изоляцией данных между клиниками, управление через суперадмин-панель. Платформа масштабируется горизонтально.

**5. Быстрая миграция**  
Реализованы скрипты импорта из популярных устаревших систем (Vetais). Клиент не теряет историю болезней пациентов.

**6. ИИ-ассистент**  
Интеграция с OpenAI для помощи врачам в реальном времени — на старте только у единиц конкурентов.

## 10. Рынок и потенциал

- В России насчитывается **более 7 000 ветеринарных клиник**, из которых большинство до сих пор используют устаревшее ПО или работают частично на бумаге
- Рынок домашних животных в России устойчиво растёт: по данным отрасли, более 60% городских семей имеют питомца
- Средний чек на ветеринарные услуги растёт ежегодно на 15–20%
- Даже при проникновении в **10% рынка** (700 клиник) на среднем тарифе «Профи» (24 900 ₽/мес) ARR составит **~210 млн ₽**
- Дополнительный потенциал — страны СНГ (Казахстан, Беларусь, Армения), где аналогичная проблема отсутствия современных vet-ERP систем

## 12. Технологические барьеры входа

- **Доменная экспертиза:** система разрабатывалась в тесном контакте с практикующими ветеринарами и управляющими клиник — это сложно воспроизвести «снаружи»
- **Инфраструктура миграции:** готовые скрипты импорта из конкурентных систем — ключевое преимущество при смене клиентами поставщика
- **Наработанная кодовая база:** 10 000+ строк серверного кода, полноценный frontend, три платформы — 2–3 года разработки
- **Реальные данные клиентов:** 100 000+ клиентских записей и 520 000+ счетов — живая нагрузка, подтвердившая надёжность системы
